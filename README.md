# GEeks Shop

Учебное SPA-приложение на React, JSX и JavaScript с API Escuelajs.

## Запуск

```bash
npm install
npm run dev
```

## Возможности

- Каталог с поиском по названию, категорией, диапазоном цен и сортировкой.
- Фильтры и номер страницы в query-параметрах URL.
- Пагинация по `offset` и `limit` (12 товаров на страницу).
- Страница товара, избранное и корзина.
- Создание и редактирование товара, удаление товара с подтверждением.

Избранное и корзина хранятся в браузере через Zustand. ID созданных этим приложением товаров сохраняются в `localStorage`, поэтому интерфейс редактирования и удаления доступен для них только в том же браузере. API публичное: при создании товара добавьте свою фамилию в название и изменяйте/удаляйте только свои товары.

## Проверки

```bash
npm run build
npm run lint
```

API: `https://api.escuelajs.co/api/v1`.
